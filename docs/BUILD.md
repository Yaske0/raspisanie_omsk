# Сборка `.exe` в облаке (подробно)

На компьютере ничего ставить не нужно — только браузер. Сборка идёт бесплатно
на серверах GitHub, вы получаете готовый файл.

## 1. Репозиторий и файлы

1. Зарегистрируйтесь на https://github.com и создайте репозиторий
   (**New** → имя любое → можно **Private** → **Create repository**).
2. Загрузите файлы: **Add file → Upload files**.

> ⚠️ Загружайте **содержимое** папки `app` в корень репозитория, чтобы в корне
> оказались `run.py`, `requirements.txt`, а также папки `aeroomsk`, `.github` и
> `docs`. Тогда README покажется на главной странице, а сборка найдёт все файлы.

> ⚠️ Папка `.github` при перетаскивании иногда молча не загружается (браузеры
> пропускают папки, начинающиеся с точки). Если её нет в репозитории, создайте
> файл вручную: **Add file → Create new file**, имя
> `.github/workflows/build.yml`, и вставьте содержимое из проекта.

## 2. Запуск сборки

Откройте вкладку **Actions**. Сборка запустится сама после загрузки файлов (или
нажмите **Run workflow → Run workflow**). Идёт 3–5 минут.

## 3. Скачать результат

Когда напротив запуска появится зелёная галочка — откройте его и внизу в разделе
**Artifacts** скачайте **РасписаниеСмены-windows** (это zip). Внутри —
`РасписаниеСмены.exe` и `config.json`.

## Возможные вопросы

- **На вкладке Actions пусто / «выберите workflow».** Значит файл
  `.github/workflows/build.yml` не загрузился — создайте его вручную (см. выше).

- **Сборка падает с `Script file 'run.py' does not exist`.** Файлы лежат не в
  корне, а внутри подпапки (например `app/`). Решение — либо перезалить
  содержимое `app` в корень, либо добавить в `build.yml` под `jobs: build:`
  блок, указывающий рабочую папку:

  ```yaml
  jobs:
    build:
      runs-on: windows-latest
      defaults:
        run:
          working-directory: app
  ```

  и в шаге выгрузки артефакта прописать пути с префиксом `app/`
  (`app/dist/РасписаниеСмены.exe`, `app/dist/config.json`).

- **Предупреждение про «Node.js 20 is deprecated».** Это не ошибка, на сборку не
  влияет. При желании можно поднять версии экшенов: `actions/checkout@v5`,
  `actions/setup-python@v6`.

## Обновление программы

Чтобы обновить после правок: замените изменённые файлы в репозитории
(через карандаш «Edit» или повторной загрузкой) и сделайте **Commit** —
сборка перезапустится автоматически, заберите новый `.exe` из **Actions**.
